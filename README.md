# jebfarneth.com

Personal portfolio site. Single-file HTML/CSS/JS with a manila folder UI and a three-tab layout (Projects, Resume, Contact).

## Stack

- HTML / CSS / JavaScript (single file, no build tools)
- SVG panel geometry
- EB Garamond, JetBrains Mono, Times New Roman
- Hosted on AWS S3 + CloudFront
